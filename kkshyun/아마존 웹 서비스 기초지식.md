### 💡 주요 개념 미리보기

> AWS(아마존 웹 서비스)란?AWS는 컴퓨팅, 스토리지, 데이터베이스 등을 제공하는 클라우드 컴퓨팅 서비스다. 쉽게 말해, 서버와 네트워크를 직접 구축하지 않고 필요한 만큼만 빌려 쓸 수 있는 서비스라고 할 수 있다.
>

> AWS의 주요 특징
>
>
> ✔ 다양한 서비스 제공 → Amazon EC2(서버), Amazon S3(스토리지) 등 인프라 구축 가능
>
> ✔ 사용한 만큼 지불 → 종량제 요금 구조로 불필요한 비용 절감 가능
>
> ✔ 쉬운 관리 → 관리 콘솔과 매니지드 서비스 제공
>
> ✔ 보안 및 운영 자동화 → 업데이트 및 보안 관리 부담 감소
>

> AWS는 전문 지식 없이도 쉽게 사용할 수 있도록 다양한 도구와 자동화 기능을 제공해 스타트업부터 대기업까지 유연하고 확장 가능한 IT 인프라를 구축하는 데 많이 활용되고 있다.
>

### 1.1 아마존 웹 서비스란: 아마존이 제공하는 클라우드 서비스

- `AWS` : 클라우드 컴퓨팅 서비스의 하나
    - 클라우드 컴퓨팅 서비스 : 서버 및 네트워크 등을 인터넷으로 빌려주는 서비스로, 언제 어디서든지 사용할 수 있음 ex) AWS - Amazon EC2, Amazon S3
- AWS의 다양한 서비스를 조합하여 모든 애플리케이션과 인프라를 구축할 수 있음
- AWS를 사용하면 여러 사업자에게 각각 빌려야 했던 인프라를 일괄로 빌릴 수 있고, 운영체제나 웹 서버, 데이터베이스 서버 등에 필요한 소프트웨어까지 통째로 사용 가능함
- AWS가 제공하는 서비스가 다양하기 때문에 AWS만으로도 필요한 기능을 대부분 구축할 수 있으며, 여러 서비스를 조합하여 구축하기 쉬움
- 종량제 임대 구조이므로 필요하다고 생각하는 만큼만 지불하여 쓸 수 있음
- 다양한 방법을 제공하기 때문에 전문가가 아니어도 쉽게 사용이 가능하고 인터넷이 가능한 곳이라면 언제 어디서든 조작이 가능함
- 서비스 대부분이 한국어를 지원함
- 서버를 설치하여 운영하는 데이터 센터를 여러 국가에 보유하고 있어서 글로벌 확장이 쉬움

### 1.2 AWS의 서비스: 165개 이상의 서비스 제공

- AWS는 IT 전반과 관련된 인프라의 대부분을 제공하고 있음
- AWS의 대표적인 서비스
    - Amazon EC2
        - 컴퓨팅 용량을 제공함
        - 서버, OS, 소프트웨어 등을 세트로 사용 가능함
        - 자유롭게 소프트웨어를 설치하고 시스템을 구축할 수 있으며 이미 세팅된 서버를 사용하는 것도 가능함
    - Amazon S3
        - 오브젝트 스토리지 서비스
        - 웹 서버 및 파일 서버용 파일을 보관하는 장소로 사용 가능
    - Amazon VPN
        - AWS 계정 전용의 가상 네트워크
        - 네트워크 및 서브넷의 범위, 라우팅 테이블 및 네트워크 게이트웨이 등을 설정하고, 가상 네트워크 환경을 구성함
    - Amazon RDS
        - 관계형 데이터베이스(MySQL, PostgreSQL 등)를 클라우드에서 이용할 수 있는 서비스
    - Amazon Route 53
        - 웹 서버에 필수인 DNS 기능을 제공함
    - Amazon Managed Blockchain
        - 블록체인 네트워크를 생성, 관리할 수 있는 도구
        - 데이터 위조 및 변조를 확인하는 기반으로 이용 가능

### 1.3 AWS의 비용: 초기 비용은 저렴하지만 운영 비용이 조금 비싸다

- AWS는 서비스에 따라 요금 체계가 다름
- 대부분은 종량제를 도입하고 있어서 ‘사용한 서비스 1개당 금액 + 사용한 분’의 과금 형태가 많음
- 최소로 필요한 만큼으로 시작하고 필요할 때 늘리면 됨
- 초기 비용이 들지 않는 대신 운영 비용이 들기 때문에 경우에 따라 정액제 임대나 자사에서 준비하는 편이 저렴할 수 있음
- 돌발적으로 접속 수가 늘어나는 웹 사이트의 경우는 AWS의 유연성이 큰 장점이 됨
- AWS는 운영에 대한 부분을 맡길 수 있어 관리하는 사람이 없어도 되기 때문에 인건비의 축소로 인해 비용을 절감할 수 있음
- `프리티어` : AWS에서는 쉽게 시작할 수 있도록 다양한 시스템을 구현하고 테스트해볼 수 있게 12개월 동안 무료로 사용이 가능함

### 1.4 AWS의 사용 방법: 누구라도 쉽게 서비스를 이용할 수 있음

- AWS는 `관리 콘솔`과 `매니지드 서비스`가 있어 누구라도 쉽게 서비스를 사용할 수 있음
- 관리 콘솔
    - 웹 브라우저의 GUI로 AWS를 조작하는 화면
    - 서비스별로 고유 화면(대시보드)가 있어서 다양하게 서비스를 관리할 수 있음
- 매니지드 서비스
    - AWS가 관리하는 서비스의 통칭
    - 대표적인 매니지드 서비스로 Amazon S3, Amazon RDS 가 있음
    - 백업 및 업데이트가 자동으로 이루어짐 → 관리자가 수동으로 할 필요 없기 때문에 관리 부담 줄어듦
    - 소프트웨어 업데이트와 같은 운영 업무를 자동화할 수 있기 때문에 항상 안전한 상태로 운영 가능


### 1.5 AWS의 도입 사례: 대기업이나 정부기관에서 도입하는 경우도 다수

- 국내에도 AWS 도입 사례는 늘어나고 있음
- 모든 것을 AWS로 도입하는 것이 아닌 선택적으로 다른 임대 서비스 등과 조합하는 것도 좋음

### 1.6 AWS의 도입 방법: 계정을 만들고 로그인하면 된다

- AWS는 웹 브라우저를 통해 쉽게 계약할 수 있음
- AWS 계정을 만들고 각 서비스를 신청하면 완료됨
- AWS 계정 : AWS를 사용하기 위한 계정
- AWS는 전문적인 지식 없어도 사용 가능하지만 시스템을 구축하고 운영하려면 네트워크나 서버 등의 어느정도 지식이 필요함
