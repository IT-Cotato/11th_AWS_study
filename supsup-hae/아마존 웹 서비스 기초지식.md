## AWS란?

> **클라우드 컴퓨팅 서비스(Cloud Computing Service)**  
> 서버 및 네트워크 등을 인터넷으로 빌려주는 서비스로 시간적, 공간적 제약이 없습니다.

### 특징

1. 서비스를 조합하여 모든 애플리케이션과 손쉽게 인프라 구축 가능 (컴퓨팅, 스토리지, DB 등)
2. OS, WAS, DB, 인프라를 일괄로 빌릴 수 있습니다.
3. 매년 AWS에서 제공되는 서비스의 확장으로 여러 서비스를 조합하여 구축하기 쉽습니다.
    - AWS - 외부 시스템 | 네트워크 연동으로 확장이 용이합니다.
4. 사용량에 따라 금액을 측정하기 때문에 경제적 이점이 있습니다.
5. 기술을 잘 모르더라도 운영하는 다양한 방법을 제공하여 초심자에게 좋은 서비스입니다.
6. 한국어와 한국 원화 결제가 가능하며, 국내에 APN(Amazon Partner Network) 파트너 기업이 존재합니다.
7. Compliance에 인증 및 검증되어 있으며 법령, 규정, 프라이버시 기준(ISMS 포함)을 준수합니다.
8. 전 세계 21개 지역, 66개 시설에서 운영하고 있어 글로벌 확장이 용이합니다.

## AWS 서비스

> **IT 전반과 관련된 인프라 대부분을 제공하는 서비스 (200개 이상)**

- 서버, 네트워크에 필요한 장치, 개발 도구, 계정 관리를 위한 장치를 사용할 수 있습니다.
- 목적에 따른 서비스 제공 → 테스트 목적의 서버 배포 시에도 유용하게 사용 가능합니다.

**웹 서버를 구축하고 싶은 경우**
- **서버**: EC2
- **운영 체제**: AMI
- **IP 주소**: Elastic IP
- **스토리지**: S3
- **도메인 관리**: Route 53
- **데이터베이스**: RDS

**모바일 시스템을 구축하고 싶은 경우**
- **애플리케이션 서버**: EC2
- **데이터베이스 서버**: RDS
- **알림 서비스**: SNS
- **스토리지**: S3
- **IP 주소**: Elastic IP
- **인증 서비스**: Cognito

**콘텐츠를 배포하고 싶은 경우**
- **서버**: EC2
- **캐시 서버**: CloudFront
- **IP 주소**: Elastic IP
- **도메인 관리**: Route 53

### 종류

**EC2**  
Amazon Elastic Compute Cloud(EC2)는 컴퓨팅 용량을 제공하는 서비스입니다. 간단히 말하면 서버, OS, 소프트웨어 등을 세트로 사용할 수 있습니다. 다양한 사양이 준비되어 있고 자유롭게 소프트웨어를 설치하며 시스템을 구축할 수 있으며, 이미 설정된 서버를 사용하는 것도 가능합니다. 임시 정지 중에는 언제든 성능을 높이거나 낮출 수 있습니다.

**S3**  
Amazon Simple Storage Service(S3)는 오브젝트 스토리지 서비스입니다. 웹 서버 및 파일 서버용 파일을 보관하는 장소(스토리지)로 사용할 수 있습니다. S3는 강력하고 다양한 기능이 있어 장애에 대비하여 여러 AWS 리전과 연동할 수 있는 기능이나 다른 서비스와 연동하는 기능도 갖추고 있습니다. 파일 크기는 최대 5TB이며, 전체 용량의 제한은 없습니다.

**RDS**  
Amazon RDS는 관계형 데이터베이스의 대표격인 6종류(Amazon Aurora, PostgreSQL, MySQL, MariaDB, Oracle Database, SQL Server)를 클라우드에서 이용할 수 있는 서비스입니다.

**Route 53**  
Amazon Route 53은 DNS(도메인 네임 서버)입니다. 웹 서버에 필수인 DNS 기능을 제공합니다.

**Elastic IP**  
Elastic IP 주소는 서버에 필수인 정적 공인 IP 주소를 제공합니다. EC2 및 ELB와 조합하여 사용합니다.

## 비용

> **사용한 만큼 지불하는 종량제로 최소한의 준비로 프로젝트를 시작하고, 필요할 때마다 유동적으로 늘릴 수 있습니다.**

![image 2](https://github.com/user-attachments/assets/6df9aa28-90ce-42a5-b217-7f2c4bfe7b00)
> t3.micro 인스턴스 + 30GB SSD 스토리지 + 150GB/Month +옵션 X 산출 예시



**요금 산출 방법 (EC2)**: 인스턴스 사용량 (가동 시간 × 단가) + EBS 요금 (용량 × 단가) + 통신료 + 옵션

**장점**:
- 단시간 트래픽이 증가하는 웹사이트는 AWS의 유연성을 활용할 수 있습니다.
- 운영에 대한 부분을 AWS에 위임하기 때문에 관리하는 사람이 없어도 됩니다. (전문적 지식 불필요)

**단점**:
- 초기 비용이 들지 않는 대신 운영 비용이 발생하여, 경우에 따라 정액제나 자사 서버를 이용할 수 있습니다.
- 특정 서비스는 최저 요금이 있기도 하며, 서비스 1개당 요금이 발생하는 체계도 존재합니다.
- 트래픽이 일정한 서비스는 비용 절감 시 인건비 축소에 중점을 맞춰야 합니다.

## 사용 방법

> **전문가가 없어도 쉽게 조작 가능한 기능을 제공합니다**

### 관리 콘솔

> **웹 브라우저의 GUI로 AWS를 조작하는 화면**

- 서비스 설정, 운영할 리전 선택, 계정 관리, 서비스의 리소스 그룹 검색 및 사용, 자료 열람 등이 가능합니다.

### 매니지드 서비스

> **AWS가 관리하는 서비스의 통칭으로 백업 및 업데이트가 자동으로 이루어져 관리 부담이 줄어듭니다.**

- S3, RDS가 대표적인 예로, S3는 자동으로 용량이 증가하기 때문에 편리합니다. (비용 측면에서는 주의 필요)
- 소프트웨어 업데이트 같은 운영 업무를 자동화할 수 있어 안전한 상태의 운영이 가능합니다.
- 특정 기준이 충족된 채로 운영되도록 하기에 일정 수준을 기대할 수 있습니다.
- 전문가가 없는 경우에도 높은 수준의 보안성을 제공합니다.
