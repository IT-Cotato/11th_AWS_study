## 6.1 Amazon VPC

### 6.1.1 Amazon VPC(Amazon Virtual Private Cloud)

> **AWS 계정 전용 가상 네트워크 서비스로 AWS에서 제공하는 리소스만 설치 가능**

- EC2, RDS의 경우 사용하지 않으면 서버 생성이 불가능하기 때문에 반드시 사용해야 한다.

### 6.1.2 구성

- VPC는 논리적으로 격리된 가상 네트워크로 구성되며, 서브넷과 게이트웨이를 통해 네트워크 환경을 구축한다.

### 6.1.3 기능

> **네트워크, 서브넷 범위, 라우팅 테이블, 네트워크 게이트웨이 등의 가상 네트워킹 환경 구성 설정 가능**

| 항목              | 내용                                                                                                    |
|-------------------|---------------------------------------------------------------------------------------------------------|
| CIDR 블록         | 서버에서 사용할 네트워크를 나타낸다. VPC를 생성할 때 네트워크 블록을 CIDR로 정한 다음 이를 더 작은 서브넷으로 나누어 사용된다. |
| 서브넷 마스크     | 네트워크의 크기를 가늠하는 것이다. CIDR는 서브넷 마스크의 표기법 중 하나이다.                           |
| 가용 영역         | 서버를 구축할 물리적인 장소이다.                                                                        |
| 인터넷 게이트웨이 | 인터넷과 연결을 위한 출입구 역할. VPC를 인터넷에 연결하지 않으면 외부에서 들어오는 것과 나가는 것 모두 차단된다. |
| 라우팅            | 어떤 네트워크를 어디로 보낼지 결정하고, 이러한 게이트웨이의 관련 설정이 있다.                          |
| 라우팅 테이블     | 경로 설정에 대한 정보가 기록된 테이블이다.                                                             |
| 보안 그룹         | AWS가 제공하는 가상 방화벽이다. 인스턴스 단위로 설정하여 들어오는 네트워크를 제어하는 기능이다.        |
| 네트워크 ACL      | AWS가 제공하는 가상 방화벽이다. 서브넷 단위로 설정된다.                                               |

### 6.1.4 네트워크 특징과 라우팅 테이블

> **물리적인 라우터가 아닌 소프트웨어가 라우터 역할을 수행한다**

- 라우팅은 라우팅 테이블에 따라 동작하는데 테이블 하나에 서브넷을 여러 개 설정 가능하다.
- 서브넷 사이의 통신을 라우터 없이 직접 통신 가능하다.
- VPC 하나에 인터넷 게이트웨이 1개만 설정 가능하다 (명시적인 IP 주소가 부여되지 않는다).
