## 6.1 Amazon VPC란: AWS에서 생성하는 가상 네트워크

### 6.1.1 Amazon VPC란

> 웹 서버나 데이터베이스 서버, EC2, RDS와 같은 서버들은 네트워크에 연결돼있어야 한다.
>
- 이러한 네트워크를 구축하기 위해 사용되는 것이 Amazon Virtual Private Cloud 이다.
    - AWS 계정 전용 가상 네트워크 서비스
    - AWS에서 제공하는 리소스만 설치 가능
        - 리소스를 사용하기 위해 반드시 필요

### 6.1.2 VPC의 구성

- VPC 내에 서버를 설치하면 해당 네트워크에 소속되지만, 별도로 설정하지 않으면 VPC 자체는 격리된 네트워크가 된다
- 외부와 통신라려면 VPC를 인터넷, 회사 내 LAN과 연결해야 함


### 6.1.3 VPC의 기능

- VPC는 가상 네트워킹 환경을 설정 가능
    - 네트워크, 서브넷 범위, 라우팅 테이블, 네트워크 게이트웨이 ..

### 6.1.4 VPC 네트워크의 특징과 라우팅 테이블

<aside>
💡

VPC 네트워크(클라우드)와 일반 네트워크의 가장 큰 차이점은 라우터이다.

</aside>

- VPC는 물리적인 라우터가 아닌 소프트웨어가 라우터 역할을 하며 라우팅 수행
    - 라우팅은 설정된 라우팅 테이블에 따라 동작
        - 라우터는 IP주소 갖지 않음
    - 라우팅 테이블 하나에 서브넷 여러개 설정 가능
- 물리적인 서버의 경우 LAN 케이블과 와이파이로 라우터와 연결하는 반면 클라우드는 라우팅 테이블로 연결
- VPC의 경우 서브넷 사이의 통신을 라우텅 없이 직접 통신 가능
- VPC 하나에 인터넷 게이트웨이 한 개만 설정 가능
    - IP 주소 갖지 않음
